# 作品简介（≤500字 · 直接填表）

## 作品名称
跨文化网盟管理 Skill 集合 — 基于 AI Agent 的多区域 Affiliate 自动化运营系统

## 作品简介

M COMPANY 作为跨境网盟公司，服务全球三类广告主——
🇧🇷 巴西本土出海公司、🇪🇺 欧洲出海互联网公司、🇨🇳 中国出海广告主；
流量来自 🇧🇷 巴西本地渠道、🇨🇳 中国出海 DSP/ADX/SSP、🌏 东南亚互联网公司。
日常运营面临三大痛点：**数据处理高度重复**（每周 5+ 份报表手动清洗耗时 3-5 小时）、**跨文化沟通效率低**（三类广告主 × 三类流量源，沟通风格差异巨大，邮件往返 5-8 次）、**预算分配依赖经验**（人工判断导致 20-30% 预算浪费在低质流量上）。

本作品将网盟运营知识封装为 **14 个可复用 AI Agent Skill**，采用五层架构：

**Layer 1 数据接入层**：从 OCR 结算单自动提取渠道数据（crm-channel-extraction）、自动对账标记异常（crm-settlement-verification）。

**Layer 2 数据分析层**：Wish List 智能解析（wish-intelligence-collector / regional-wish-classifier）；多 MMP 归因引擎基于 Source Bank 去重（multi-mmp-attribution-engine）；预算汇总生成优化建议（ai-budget-optimizer）；区域市场情报（geo-market-intel-engine）。

**Layer 3 反作弊与归因层**：PA 渠道数据导出（pa-channel-export）；专项 PA 分析（pa-channel-export）；PA 报告自动化工作流（pa-report-workflow）。

**Layer 4 智能决策层**：JXXXX Campaign 转化漏斗分析输出渠道 CAP 建议（conversion-funnel-intelligence）；NXXX Campaign 盈亏核算标记负 ROI 渠道（cross-regional-revenue-audit）；定时监控数据异常预警（macro-monitoring-agent）。

**Layer 5 跨文化协作层（核心差异化）**：全球化跨文化沟通引擎（cross-cultural-negotiation-copilot v2.0），覆盖 🇧🇷 巴西 / 🇨🇳 中国 / 🇪🇺 欧洲 / 🌏 东南亚 / 🇸🇦 中东 五大文化圈，包含 Soft Wording / Validation Framing / Internal Coordination 三大策略，解决多文化沟通中的合作关系破裂问题。

**技术创新**：每个 Skill 内嵌完整可执行 Python 脚本，AI Agent 可自动调用；所有输出自动处理编码适配（utf-8-sig → Excel 无乱码）；业务规则来自真实运营经验而非通用 Prompt；支持同一事项一键生成 5 种文化版本。

**应用效果**：月度对账从 1 天压缩至 30 分钟；PA 报表制作 100% 自动化；Wish List 拆分 95% 效率提升；跨文化沟通往返次数减少 80%；新人上手时间从 2 周缩短到 2 天。
